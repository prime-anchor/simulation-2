# ①課題名

顧客台帳とLP問い合わせの参照シミュレーション

## ②課題内容（どんな作品か）

企業名を顧客台帳に登録し、LPからの問い合わせが届いたときに、その企業が台帳に載っているかを確認できるアプリです。画面の左側に顧客登録と台帳、右側にLPの公開と問い合わせを配置しました。

### アプリの仕組み

- 顧客登録では企業名を入力します。台帳から企業名の編集や登録の削除ができます。
- 「LPを公開する」を押すと、PrimeAnchor（当社）のLPプレビューが表示されます。約3秒後から、株式会社グー、株式会社チョキ、株式会社パー、株式会社グーの順に問い合わせが自動で届きます。
- 問い合わせのたびに台帳を参照します。同じ企業名があれば「登録済み」と表示して問い合わせ件数を加算し、見つからなければ「新規」と表示して企業を台帳に追加します。

### 操作方法

1. [index.html] をブラウザで開きます。
2. 空の台帳に「株式会社グー」を登録します。
3. 「LPを公開する」を押し、右側に表示される問い合わせを確認します。
4. 株式会社グーが「登録済み」、株式会社チョキと株式会社パーが「新規」と表示されます。最後の問い合わせが届くと、台帳の株式会社グーの行に「LPからの問い合わせ 2件」と表示されます。

## ⑤工夫した点・こだわった点

- `setTimeout()` で問い合わせに時間差をつけ、LPを公開してから問い合わせが届く流れを再現しました。
- 問い合わせごとにその時点の台帳を参照することで、手入力での登録とLP経由の追加を、次の照合に反映できるようにしました。
- 問い合わせ欄は企業名と「新規」「登録済み」に絞りました。罫線で行を区切り、右端に区分をそろえています。
- アイボリーとネイビーを基調に、公開中の表示に朱色、LP内の「相談する」にゴールドを使いました。
- 企業名と問い合わせ件数はブラウザの `localStorage` に保存し、再読み込み後も台帳を使えるようにしました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
